# CEO-Pulse Sovereign Suite

A production-inspired executive operations dashboard built with React, Vite, TypeScript, and Tailwind CSS.

## Features
- Real-time executive dashboard UI
- Secure governance and approval cards
- Operational pulse monitoring
- Strategic goals and risk views
- PWA-ready manifest and service worker
- Responsive dark UI for web and mobile

## Getting started

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Production build

```bash
npm run build
```
